# 前端页面信息架构与线框 V1

状态：`FROZEN_WIREFRAME_V1`

依据：

- `FRONTEND_STORY_CHAIN.md`
- `FRONTEND_DATA_MAPPING.md`
- `FRONTEND_INTERACTION_FLOW.md`

## 1. 页面信息架构

```text
登录
├── 调度中心
│   ├── 运行总览
│   ├── 实时监控
│   ├── 决策证据
│   ├── 周期故事
│   └── 历史回放
├── 车端 HMI
└── 铲端 HMI
```

调度中心的固定顶栏统一展示：

```text
系统名称 | Simulation | Run | 场景 | 仿真时间 | MQTT状态 | 现场在线状态 | 用户
```

## 2. 调度中心公共框架

```text
┌─────────────────────────────────────────────────────────────┐
│ 系统名称  Simulation / Run / 场景 / 仿真时间 / 连接状态      │
├──────────┬──────────────────────────────────────────────────┤
│ 运行总览 │                                                  │
│ 实时监控 │                  当前页面内容                    │
│ 决策证据 │                                                  │
│ 周期故事 │                                                  │
│ 历史回放 │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

切换 Run 时，所有页面数据必须一起切换，不保留上一个 Run 的车辆、事件或统计。

## 3. 运行总览

回答：当前运行怎么样？

```text
┌─────────────────────────────────────────────────────────────┐
│ Run身份与数据质量                                           │
├────────────┬────────────┬────────────┬─────────────────────┤
│ 在线车辆   │ 运行车辆   │ 完成周期   │ 异常/陈旧数据       │
├────────────┴────────────┴────────────┴─────────────────────┤
│ 车辆与铲装点运行概览        │ 最近事件                     │
│                              │ DISPATCH / CONTROL / ACK     │
├──────────────────────────────┴──────────────────────────────┤
│ 生产结果：有效完成量、周期耗时、运行效果                    │
└─────────────────────────────────────────────────────────────┘
```

## 4. 实时监控

回答：现在发生什么？

```text
┌─────────────────────────────────────────────────────────────┐
│ 筛选：全部 / 运行 / 等待 / 异常 / stale                     │
├───────────────┬──────────────────────────┬──────────────────┤
│ 车辆/铲装点列表│          矿区地图        │ 对象详情         │
│                │                          │ 状态、任务、目标 │
│                │                          │ 速度、更新时间   │
│                │                          │ [查看决策证据]   │
│                │                          │ [人工改派]       │
└───────────────┴──────────────────────────┴──────────────────┘
```

人工改派链路已经完成并通过既有验收。现行实现中，前端按既有装载点/卸载点固定集合展示目标，
后台仍独立校验车辆在线、行驶态、载荷兼容、目标存在和路线可达；AnyLogic 在安全节点应用新路线，
并通过 MQTT 返回 `EXECUTED / REJECTED`。前端只在收到 `EXECUTED` 后显示“已执行”，同时保留 Command、Ack、DecisionTrace 与 Audit 证据。

## 5. 决策证据

回答：为什么这样调度，指令是否执行？

```text
┌─────────────────────────────────────────────────────────────┐
│ 筛选：车辆 / DISPATCH / CONTROL / 结果 / 仿真时间           │
├──────────────────┬──────────────────────────────────────────┤
│ 决策记录列表     │ 触发事件                                 │
│                  │   ↓                                      │
│                  │ 网关状态与候选状态                       │
│                  │   ↓                                      │
│                  │ 决策输入快照（调度可含27维输入）         │
│                  │   ↓                                      │
│                  │ 决策输出 → 后台校验 → COMMAND → ACK      │
└──────────────────┴──────────────────────────────────────────┘
```

## 6. 周期故事

回答：一次运输过程是否闭环？

```text
UNLOAD_FINISHED(previous)
  → DISPATCH_TRIGGERED
  → HAUL_EMPTY_START
  → ARRIVE_SHOVEL
  → LOAD_START
  → LOAD_FINISHED
  → HAUL_FULL_START
  → ARRIVE_DUMP
  → UNLOAD_START
  → UNLOAD_FINISHED(current)
```

```text
┌──────────────────┬──────────────────────────────────────────┐
│ Cycle列表        │ Cycle时间线                              │
│ 车辆/状态/耗时   │ 已采集事件：实线                         │
│                  │ 缺失事件：虚线并标记“数据不足”           │
└──────────────────┴──────────────────────────────────────────┘
```

## 7. 历史回放

回答：指定仿真时刻发生了什么？

```text
┌─────────────────────────────────────────────────────────────┐
│ 只读回放 | Run | 仿真时间 simTime | 查询墙钟 queryWallTime  │
├──────────────────────────────────────┬──────────────────────┤
│ 历史地图与对象状态                   │ 同时刻事件与详情     │
├──────────────────────────────────────┴──────────────────────┤
│ 仿真时间轴  ◀──────●──────────────────────────────▶         │
└─────────────────────────────────────────────────────────────┘
```

回放以 `simTime` 为主，墙钟时间仅用于辅助查询；回放状态禁止发送指令。

## 10. 页面跳转主链

```text
运行总览
  → 实时监控选择车辆
  → 查看任务与目标
  → 查看决策证据
  → 查看 COMMAND_ACK
  → 查看所属 Cycle
  → 必要时进入历史回放
```

## 11. 前端职责边界

前端负责数据展示、用户操作、状态反馈和证据浏览。

前端不负责调度计算、控制计算、路径规划、状态推断、数据补全或模型解释生成。
